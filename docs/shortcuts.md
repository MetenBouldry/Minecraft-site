# Корисні комбінації та команди

## VS Code — редагування

| Клавіші | Що робить |
| --- | --- |
| Tab / Shift+Tab | Збільшити / зменшити відступ виділених рядків |
| Ctrl+/ | Закоментувати / розкоментувати |
| Alt+↑ / Alt+↓ | Перемістити рядок вгору / вниз |
| Shift+Alt+↓ | Дублювати рядок |
| Ctrl+D | Виділити наступне таке саме слово |
| F2 | Перейменувати змінну/функцію скрізь |
| Ctrl+Space | Автодоповнення (менше опечаток) |
| Ctrl+. | Швидке виправлення (лампочка) |
| Shift+Alt+O | Відсортувати імпорти (Ruff) |
| Shift+Alt+F | Відформатувати файл |
| Ctrl+Z / Ctrl+Y | Скасувати / повернути |

## VS Code — навігація

| Клавіші | Що робить |
| --- | --- |
| Ctrl+P | Відкрити файл за назвою |
| Ctrl+Shift+P | Палітра команд |
| Ctrl+F / Ctrl+H | Пошук / заміна (Alt+W — лише ціле слово) |
| Ctrl+Shift+F | Пошук по всьому проєкту |
| F12 | Перейти до оголошення функції/змінної |
| Ctrl+G | Перейти до рядка |
| Ctrl+` | Термінал |
| Ctrl+Shift+M | Панель Problems |
| Ctrl+Shift+G | Git |
| Ctrl+Shift+X | Розширення |

## PyCharm

| Клавіші | Що робить |
| --- | --- |
| Tab / Shift+Tab | Відступ |
| Ctrl+/ | Закоментувати |
| Ctrl+D | Дублювати рядок |
| Ctrl+Y | Видалити рядок |
| Alt+Shift+↑ / ↓ | Перемістити рядок |
| Shift+F6 | Перейменувати скрізь |
| Alt+Enter | Швидке виправлення |
| Ctrl+Alt+L | Відформатувати файл |
| Ctrl+Alt+O | Прибрати зайві / відсортувати імпорти |
| Shift Shift (двічі) | Шукати все (файли, дії, класи) |
| Ctrl+Shift+N | Відкрити файл за назвою |
| Ctrl+Shift+A | Знайти дію (як палітра команд) |
| Ctrl+Shift+F / Ctrl+Shift+R | Пошук / заміна по проєкту |
| Ctrl+B (або Ctrl+клік) | Перейти до оголошення |
| Ctrl+G | Перейти до рядка |
| Alt+F12 | Термінал |
| Alt+6 | Панель Problems |
| Ctrl+K / Ctrl+Shift+K | Коміт / Push |

## Браузер

| Клавіші | Що робить |
| --- | --- |
| F12 | Інструменти розробника (Console, Network) |
| Ctrl+Shift+N | Інкогніто (без кешу) |
| Ctrl+F5 | Оновити без кешу |

## Термінал (PowerShell)

| Команда | Що робить |
| --- | --- |
| `.venv\Scripts\Activate.ps1` | Увімкнути venv (має з'явитися `(.venv)`) |
| `uvicorn app.main:app --reload` | Запустити бекенд → <http://127.0.0.1:8000/docs> |
| Ctrl+C | Зупинити бекенд |
| `pip install -r requirements.txt` | Встановити бібліотеки |
| `pip show назва` | Версія бібліотеки |

## Git

| Команда | Що робить |
| --- | --- |
| `git status` | Що змінено |
| `git branch` | Поточна гілка (позначена `*`) |
| `git checkout dev` | Перейти на dev |
| `git add .` | Додати всі зміни |
| `git commit -m "текст"` | Коміт (одна завершена думка) |
| `git push` | Відправити на GitHub |
| `git pull` | Забрати з GitHub |
| `git tag v1.x.x` + `git push origin v1.x.x` | Реліз (лише з dev!) |
