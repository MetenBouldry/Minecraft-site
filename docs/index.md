## 1. `<!DOCTYPE html>`

**Що це:** Оголошення типу документа. Повідомляє браузеру, що це — **HTML5**.

**Де:** Найперший рядок файлу. **Перед** `<html>`.

**Синтаксис:** `<!DOCTYPE html>` — без закриваючого тегу.

**Навіщо:**
- Без нього браузер переходить у **quirks mode** (режим сумісності зі старими сайтами 90-х)
- У quirks mode CSS працює непередбачувано (наприклад, `box-sizing` ігнорується)
- З ним — **standards mode** (сучасний стандарт)

**Правила:**
- **Завжди перший рядок** — перед ним не може бути нічого (навіть пробілів, коментарів)
- **Тільки** `html` як аргумент (для HTML5)
- **Регістр** не важливий — `<!DOCTYPE html>` = `<!doctype html>`, але **прийнято** великими

**Приклад:**
```html
<!DOCTYPE html>
<html lang="uk">
<head>...</head>
<body>...</body>
</html>
```

## 2. `<html lang="uk">`

**Що це:** Кореневий елемент документа. Містить **усе** — `<head>` і `<body>`.

**Де:** Одразу після `<!DOCTYPE html>`. **Закривається** в самому кінці — `</html>`.

**Атрибути:**

### `lang="uk"`

**Що це:** Мова вмісту сторінки. **ISO 639-1** код.

**Значення:**
- `uk` — українська
- `en` — англійська
- `de` — німецька
- `pl` — польська

**Навіщо:**
- **Скрін-рідери** (для людей з вадами зору) — правильно читають
- **Google** — розуміє, якою мовою контент (SEO)
- **Браузер** — вибирає правильний **шрифт**, **переноси слів**
- **Chrome Translate** — не пропонує перекласти, якщо мова співпадає

**Важливо:** `lang="uk"` — це **українська мова**, а не країна. Країна — `UA` (великі літери, без `lang`).

**Приклад:**
```html
<html lang="uk">
    <head>...</head>
    <body>...</body>
</html>
```

## 3. `<head>`

**Що це:** Службова частина документа. Містить **метадані** — те, що **не видно** на сторінці, але потрібно **браузеру** і **пошуковикам**.

**Де:** Всередині `<html>`, **перед** `<body>`. Закривається `</head>`.

**Що містить:**
- `<meta>`— кодування, viewport, опис, автор
- `<title>` — заголовок вкладки
- `<link>` — підключення CSS, іконки
- `<script>` — JS (рідко тут, краще перед `</body>`)
- `<style>` — вбудовані CSS (не рекомендується)

**Що НЕ містить:**
- Видимого контенту (текст, картинки, кнопки) — це в `<body>`

**Приклад:**
```
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Майнкрафт</title>
    <link rel="stylesheet" href="style.css">
</head>
```

[↑ На верх](#top)

### 3.1 `<meta>`

**Що це:** Метадані — інформація **про** сторінку. **Не видно** на сайті, але потрібно **браузеру**, **Google**, **соцмережам**.

**Де:** Всередині `<head>`. **Самозакриваючий** тег — `</meta>` **не потрібен**.

**Синтаксис:**
```html
<meta атрибут="значення">
```

[↑ На верх](#top)

#### 3.1.1 `charset`

`charset` — кодування
```
<meta charset="UTF-8">
```
**Що це:** Кодування символів — як **зберігаються** літери

**Значення:**
`UTF-8` — стандарт, усі мови світу ✅
`windows-1251` — стара кирилиця (не використовуй)
`ISO-8859-1` — латиниця (не для української)

**Навіщо:** без нього українські літери («ї», «є», «ґ») — **кракозябри** (типу ÐŸÑ€Ð¸Ð²Ñ–Ñ‚).

**Приклад:**
```html
<head>
    <meta charset="UTF-8">
    ...
</head>
```

[↑ На верх](#top)

#### 3.1.2 `<name>` `<content>`

`name` + `content` — метадані
```
<meta name="ключ" content="значення">
```
**Що це:** Інформація для **Google**, соцмереж, браузера.
Основні `name`:
`description` — опис для **Google**

**Приклад:**
```
<meta name="description" content="Сайт про модпак TerraFirmaGreg">
```

**Навіщо:** **Google** показує цей текст у **результатах пошуку. ~150 символів**.
`keywords` — `ключові слова (застаріло)`
**Навіщо:** раніше — для **SEO**. Зараз **Google** ігнорує.

`author` — **автор**
**Приклад:**
```
<meta name="author" content="MettenBouldry">
```
**Навіщо:** інформація про **автора**.

`viewport` — **для мобільних**
**Приклад:**
```
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
Навіщо: адаптивність. Без нього телефон показує зменшену версію десктопу.

**Параметри:**

`width=device-width` — ширина = ширина екрана

`initial-scale=1.0` — початковий масштаб 100%

`maximum-scale=1.0` — максимальний масштаб (забороняє zoom)

`user-scalable=no` — забороняє масштабування пальцями (не рекомендується для доступності)

**Приклад:**
```
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

**Open Graph (для Facebook, Telegram)**
**Приклад:**
```
<meta property="og:title" content="TerraFirmaGreg">
<meta property="og:description" content="Сайт про модпак">
<meta property="og:image" content="https://example.com/preview.jpg">
<meta property="og:url" content="https://example.com">
```
**Навіщо:** коли хтось ділиться посиланням — показує картинку, заголовок, опис.
**Примітка:** використовується `property`, а не `name`.

**Twitter Card**
**Приклад:**
```
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="TerraFirmaGreg">
<meta name="twitter:image" content="https://example.com/preview.jpg">
```
**Навіщо:** Twitter показує красиву картку при публікації посилання.

[↑ На верх](#top)

#### 3.1.3 `<http-equiv>`
http-equiv — вказівки браузеру
**Приклад:**
```
<meta http-equiv="ключ" content="значення">
```
**Що це:** «HTTP-заголовки» всередині HTML. Рідко використовується.

**Основні**:
`refresh` — автоперезавантаження
**Приклад:**
```
<meta http-equiv="refresh" content="5">
```
**Навіщо:** перезавантажити сторінку через 5 секунд. Погана практика — не використовуй.

`X-UA-Compatible` — сумісність з IE
**Приклад:**
```
<meta http-equiv="X-UA-Compatible" content="IE=edge">
```
**Навіщо:** для старого Internet Explorer. Зараз — не потрібно.

**Приклад розширеного:**
```
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Сайт про модпак TerraFirmaGreg для Minecraft">
    <meta name="author" content="MettenBouldry">
    <meta property="og:title" content="TerraFirmaGreg">
    <meta property="og:description" content="Сайт про модпак TerraFirmaGreg">
    <meta property="og:type" content="website">
    ...
</head>
```

### 3.2 `<title>`

**Що це:** Заголовок документа. Показується у вкладці браузера, а також у результатах **Google** і при додаванні в закладки.

**Де:** Всередині `<head>`. Закривається `</title>`.

**Синтаксис:**
```html
<title>Текст заголовка</title>
```

**Що не пишеться:**
❌ Не заголовок на сторінці — для цього <h1>
❌ Не підзаголовок — для цього <h2>–<h6>

**Навіщо:**
Вкладка браузера — видно зверху вікна
Історія браузера — назва сторінки
Закладки — назва при збереженні
Google — заголовок у результатах пошуку
Соцмережі — при публікації посилання

**Правила:**
Тільки текст — не можна HTML, теги, картинки
Тільки один <title> на сторінку
Обов'язково — без нього браузер покаже URL або «Untitled»
Рекомендована довжина: 50–60 символів (Google обрізає довші)
Унікальний для кожної сторінки сайту

**Приклад:**
```
<head>
    <title>Майнкрафт</title>
</head>
```

### 3.3 `<link>`

**Що це:** Елемент для підключення зовнішніх ресурсів до HTML-документа. Найчастіше — CSS-файлів, але також — іконок, шрифтів, manifest тощо.

**Де:** Всередині `<head>`.

**Синтаксис:**
```html
<link rel="тип" href="шлях">
```
**Самозакриваючий** — </link> не потрібен.

**Атрибути**
`rel` — тип зв'язку
**Що це:** «Relation» — як документ пов'язаний з ресурсом.

**Основні значення:**
`rel`	Що підключає
`stylesheet`	CSS-файл (найчастіше)
`icon`	Favicon (іконка вкладки)
`apple-touch-icon`	Іконка для iOS
`preconnect`	Попереднє з'єднання
`preload`	Попереднє завантаження
`canonical`	Канонічний URL (для SEO)
`alternate`	Альтернативна версія (RSS, мова)

`href` — шлях до ресурсу
**Що це:** «Hypertext Reference» — адреса файлу.

**Значення:**
**Відносний шлях:** style.css, ./css/style.css, ../style.css
**Абсолютний шлях: /css/style.css**

**URL:** https://example.com/style.css

`type` — MIME-тип (необов'язковий)
**Що це:** Тип файлу. Сучасні браузери самі визначають.

**Значення:**
`text/css` — для CSS (зазвичай не пишуть)
`image/png` — для PNG
`font/woff2` — для шрифтів

`media` — для яких пристроїв
**Що це:** Умова, коли застосовувати ресурс.

**Значення:**
`screen` — для екранів
`print` — для друку
`(max-width: 600px)` — для мобільних

`crossorigin` — CORS
**Що це:** Чи дозволяти міждоменні запити.

**Значення:**
`anonymous` — без credentials
`use-credentials` — з credentials
Потрібно для зовнішніх ресурсів (шрифти, CDN).

#### 3.3.1 `<Підключення CSS>`

**Приклад:**
```
<link rel="stylesheet" href="style.css">
```
**Що робить:** Завантажує `style.css` і застосовує до сторінки.

Де в `<head>`: Після `<meta>` і `<title>`, перед `</head>`.

[↑ На верх](#top)

#### 3.3.2 `<Favicon (іконка вкладки)>`

**Приклад:**
```
<link rel="icon" href="favicon.ico" type="image/x-icon">
```

**Що робить:** Показує іконку у вкладці браузера.
Формати: `.ico`, `.png`, `.svg`.

[↑ На верх](#top)

#### 3.3.3 `<Іконка для iOS>`

**Приклад:**
```
<link rel="apple-touch-icon" href="apple-touch-icon.png">
```

**Що робить:** Попереднє з'єднання з сервером — швидше завантаження.

Корисно для CDN, Google Fonts тощо.

[↑ На верх](#top)

#### 3.3.4 `<reload (пріоритет)>`

**Приклад:**
```
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>
```

**Що робить:** Завантажити ресурс раніше — до того, як він знадобиться.

[↑ На верх](#top)

#### 3.3.5 `<Стилі для друку>`

```
<link rel="stylesheet" href="print.css" media="print">
```

**Що робить:** Застосовує окремий CSS при друку сторінки.
**Чому саме тут:** після `<meta>`, після `<title>`, перед `</head>`. Стандартний порядок.

Різниця між `<link>` і `<a>`
            `<link>`	            `<a>`
**Де**	    У <head>	            У <body>
**Навіщо**	Підключення ресурсів	Посилання для кліку
**Видно**	Не видно	            Видно
**Приклад**	    CSS, favicon		    <a href="page.html">
