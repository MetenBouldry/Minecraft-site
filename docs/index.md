## 1. `<!DOCTYPE html>`

**Що це:** Оголошення типу документа. Повідомляє браузеру, що це — **HTML5**.

**Де:** Найперший рядок файлу. **Перед** `<html>`.

**Синтаксис:** `<!DOCTYPE html>` — без закриваючого тегу.

**Навіщо:**
- Без нього браузер переходить у **quirks mode** (режим сумісності зі старими сайтами 90-х)
- У quirks mode CSS працює непередбачувано (наприклад, `box-sizing` ігнорується)
- З ним — **standards mode** (сучасний стандарт)

**Правила:**
- **Завжди перший рядок** — перед ним не може бути нічого (навіть пробілів, коментарів)
- **Тільки** `html` як аргумент (для HTML5)
- **Регістр** не важливий — `<!DOCTYPE html>` = `<!doctype html>`, але **прийнято** великими

**Приклад:**
```html
<!DOCTYPE html>
<html lang="uk">
<head>...</head>
<body>...</body>
</html>
```

## 2. `<html lang="uk">`

**Що це:** Кореневий елемент документа. Містить **усе** — `<head>` і `<body>`.

**Де:** Одразу після `<!DOCTYPE html>`. **Закривається** в самому кінці — `</html>`.

**Атрибути:**

### `lang="uk"`

**Що це:** Мова вмісту сторінки. **ISO 639-1** код.

**Значення:**
- `uk` — українська
- `en` — англійська
- `de` — німецька
- `pl` — польська

**Навіщо:**
- **Скрін-рідери** (для людей з вадами зору) — правильно читають
- **Google** — розуміє, якою мовою контент (SEO)
- **Браузер** — вибирає правильний **шрифт**, **переноси слів**
- **Chrome Translate** — не пропонує перекласти, якщо мова співпадає

**Важливо:** `lang="uk"` — це **українська мова**, а не країна. Країна — `UA` (великі літери, без `lang`).

**Приклад:**
```html
<html lang="uk">
    <head>...</head>
    <body>...</body>
</html>
```

## 3. `<head>`

**Що це:** Службова частина документа. Містить **метадані** — те, що **не видно** на сторінці, але потрібно **браузеру** і **пошуковикам**.

**Де:** Всередині `<html>`, **перед** `<body>`. Закривається `</head>`.

**Що містить:**
- `<meta>` — кодування, viewport, опис, автор
- `<title>` — заголовок вкладки
- `<link>` — підключення CSS, іконки
- `<script>` — JS (рідко тут, краще перед `</body>`)
- `<style>` — вбудовані CSS (не рекомендується)

**Що НЕ містить:**
- Видимого контенту (текст, картинки, кнопки) — це в `<body>`

**Приклад:**
```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Майнкрафт</title>
    <link rel="stylesheet" href="style.css">
</head>
```
