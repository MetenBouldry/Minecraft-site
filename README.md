# TerraFirmaGreg Landing Page

Односторінковий сайт-візитка для модпаку TerraFirmaGreg. Містить адаптивний дизайн, перемикання мов (UA/EN) та індикатори статусу ігрових серверів.

## 🚀 Особливості

*   **Перемикання мов:** Динамічна зміна контенту без перезавантаження сторінки (використовує `fetch` та `localStorage`).
*   **Статус серверів:** Візуальні індикатори (зелений/червоний) для відображення поточного стану серверів (в розробці).
*   **Адаптивний дизайн:** Коректно відображається на комп'ютерах та мобільних пристроях.
*   **Градієнтний заголовок:** Використання CSS-градієнтів для створення об'ємного тексту.

## 🛠️ Технології

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Інструменти:** VS Code, Live Server

## 🏁 Як запустити локально

1.  Клонуйте репозиторій:
    `git clone https://github.com/MetenBouldry/Minecraft-site.git`
2.  Відкрийте папку `frontend` у вашому редакторі коду.
3.  Запустіть `index.html` за допомогою розширення **Live Server** (або будь-якого іншого локального сервера).
