Minecraft-site

Вебсайт для Minecraft-проєкту з підтримкою модпаку TerraFirmaGreg та Vanilla-сервера.

Проєкт перебуває в активній розробці. Основна мета — створити сайт, який об'єднуватиме інформацію про ігрові сервери, їхній статус і функції для користувачів. У майбутньому планується реалізувати реєстрацію, авторизацію, особистий кабінет та адміністративні можливості.

🎯 Мета проєкту

Створити зручний вебінтерфейс для Minecraft-серверів із можливістю поступового розширення функціональності через власний backend.

✨ Що вже реалізовано

- Головна сторінка з назвою проєкту та переліком ігрових серверів.
- Перемикання мови між українською та англійською без перезавантаження сторінки.
- Збереження вибраної мови в браузері та підтримка мовного параметра в URL.
- Адаптивне оформлення для різних розмірів екрана.
- Візуальні індикатори стану серверів: онлайн, офлайн, перевірка та невідомий статус. Підключення до реального API ще в розробці.
- Сторінки входу та реєстрації з підготовленими HTML-формами.
- Сторінка налаштувань — початкова структура інтерфейсу користувача.
- Початкова структура backend на Python із модулями авторизації, моделюванням користувача та роботою з базою даних.

🚀 Як запустити frontend локально

1. Клонуйте репозиторій:
   
   git clone https://github.com/MetenBouldry/Minecraft-site.git

2. Відкрийте папку "Minecraft-site" у редакторі коду.

3. Запустіть "src/frontend/index.html" за допомогою розширення Live Server або іншого локального вебсервера.

4. Відкрийте адресу, яку надасть локальний сервер, у браузері.

«На цьому етапі запускається лише frontend. Backend ще розробляється, тому авторизація та отримання реального статусу ігрових серверів не є повністю функціональними.»
